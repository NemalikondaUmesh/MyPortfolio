# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my technical skills, projects, professional experience, certifications, and educational background. Built to highlight my development journey, technical expertise, and software engineering projects.

## 🚀 Live Demo

**Portfolio:** https://umeshnemalikonda.vercel.app/

## ✨ Features

- Modern dark-themed user interface
- Fully responsive design for desktop, tablet, and mobile devices
- Smooth navigation and interactive elements
- Professional introduction and profile section
- Technical skills and technologies showcase
- Professional experience and internship details
- Projects with descriptions and GitHub links
- Certifications and achievements
- Educational qualifications
- Contact section with social media links
- Recruiter-friendly layout and easy navigation

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, animations, and responsive design
- **JavaScript** – Interactive functionality and dynamic elements
- **Git & GitHub** – Version control and source code management
- **Vercel** – Website deployment and hosting

## ⚙️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/NemalikondaUmesh/portfolio.git
```

2. Navigate to the project directory:

```bash
cd portfolio
```

3. Open `index.html` in your browser or use the VS Code Live Server extension.

## 🌍 Deployment

The portfolio is deployed using **Vercel** with GitHub integration.

Whenever changes are pushed to the connected GitHub production branch, Vercel automatically triggers a new deployment.
