# Explore Hyderabad

A modern tourism website showcasing famous tourist attractions in Hyderabad.

## Features

- Responsive modern UI
- Dark / Light mode
- Tourist place search
- Interactive modal popup system
- Smooth animations
- Hover effects
- Tourist information cards
- Contact section
- Loading screen

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- AOS Animation Library

## Tourist Places Included

- Charminar
- Golconda Fort
- Tank Bund
- Ramoji Film City
- Salar Jung Museum
- Birla Mandir
